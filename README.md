# Site Vitrine Hôpital Professionnel

Site vitrine professionnel pour un hôpital, réalisé avec HTML, CSS, JavaScript et Bootstrap 5.

## Fonctionnalités
- Design moderne et responsive
- Sections : Accueil, À propos, Médecins, Services, Équipements, Horaires, Contact
- Animations au scroll
- Compteurs animés
- Bouton WhatsApp flottant
- Formulaire de contact

## Technologies
- HTML5
- CSS3
- JavaScript (vanilla)
- Bootstrap 5.3
- Bootstrap Icons
